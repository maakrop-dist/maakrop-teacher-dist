1 สร้างตู้เก็บข้อมูลบน Neon (3 นาที)

  1. เข้า console.neon.tech ล็อกอินด้วย Google หรือ GitHub
  2. กดปุ่ม New Project ตั้งชื่อตามใจชอบ (เช่น my-maakrop) แล้วเลือกโซนเป็น AWS Asia Pacific (Singapore) เพื่อความเร็วสูงสุดในไทย
  3. กดปุ่ม Connect แล้วคัดลอกลิงก์ที่ขึ้นต้นด้วย postgresql://neondb_owner... มาวางในเครื่องมือด้านล่าง (ข้อ 2)
  4. กดคัดลอกโค้ด SQL จากเครื่องมือด้านล่าง → กลับไปหน้า Neon กดเมนู SQL Editor ด้านซ้าย → วางโค้ดแล้วกดปุ่ม Run สีเขียว (ขึ้น Success ถือว่าเสร็จ!)

2 เครื่องมือช่วยสร้างโค้ด SQL และค่า 5 ช่องอัตโนมัติ

วางลิงก์ฐานข้อมูลจาก Neon ลงในช่องนี้ เครื่องมือจะสร้างโค้ด SQL และปุ่มคัดลอกทีละช่อง 1–5 ให้ทันที (ทำงานในเครื่องคุณ 100% ไม่ส่งข้อมูลออกไปไหน)

ส่วนที่ 2.1 — นำโค้ดนี้ไปวางใน Neon SQL Editor แล้วกด Run (ทำครั้งเดียว)



            
ส่วนที่ 2.2 — กดคัดลอกทีละช่อง (1 ถึง 5) ไปวางในหน้าติดตั้ง Vercel

            

          

        

      


      

        
3 กดติดตั้งบน Vercel และวาง 5 ช่อง (3 นาที)

        
    
          
  1. กดปุ่มสีน้ำเงิน ติดตั้งบน Vercel (1 คลิก) ด้านบนสุดของหน้านี้
    2. 
          
  2. ล็อกอิน Vercel ด้วยบัญชี GitHub → ตั้งชื่อเว็บไซต์ของคุณ (เช่น kru-somchai) — เนื่องจากเป็น Public Repository จึงกด Deploy ได้ทันทีโดยไม่ต้องแก้ไขไฟล์ README หรือสร้าง commit เอง
    3. 
          
  3. กดปุ่ม คัดลอก จากช่องที่ 1 ถึง 5 ด้านบน มาวางลงในช่องที่มีชื่อตรงกันบนหน้า Vercel ให้ครบ
    4. 
          
  4. กดปุ่ม Deploy แล้วรอประมาณ 1 นาที ระบบจะดาวน์โหลดโปรแกรมและสร้างตารางฐานข้อมูลให้เองอัตโนมัติ
    5. 
        

      


      

        
4 เปิดหน้า /setup วางรหัสไลเซนส์แล้วเริ่มใช้งาน! (2 นาที)

        
    
          
  1. เมื่อติดตั้งเสร็จ เปิดเว็บไซต์ของคุณแล้วเติม /setup ต่อท้าย (เช่น https://kru-somchai.vercel.app/setup)
    2. 
          
  2. ขั้นที่ 1: ติ๊กยอมรับเงื่อนไข แล้ววาง รหัสไลเซนส์ (MKTH1...) จากหน้า maakrop.com/settings/self-hosted (ไม่ต้องตั้งหรือกรอก Setup Key!)
    3. 
          
  3. ขั้นที่ 2: ตั้งชื่อห้องเรียน ปีการศึกษา และสร้างอีเมลกับรหัสผ่านของครู
    4. 
          
  4. ขั้นที่ 3: กดปุ่ม "ข้ามขั้นตอนนี้และเปิดใช้งานเลย" ได้ทันที! (คีย์อัปโหลดรูป Cloudflare R2 หรือ Google Gemini AI ค่อยกลับมาใส่ทีหลังเมื่อพร้อมได้ตลอดเวลา)
    5. 
        

        
เสร็จเรียบร้อย! เข้าสู่ระบบด้วยอีเมลที่ตั้งไว้ แล้วเริ่มเช็กชื่อ กรอกคะแนน ตัดเกรด ออกข้อสอบ และทำ ปพ.5 ได้ทันทีโดยไม่มีลายน้ำ

      


      

        
5 อัปเดตเวอร์ชัน ย้ายเว็บ และวิธีแก้ปัญหาเบื้องต้น

        

          

            
อัปเดตเวอร์ชันใหม่ใน 1 คลิก

            
เปิด GitHub ของคุณ → กดแท็บ Actions → เลือก Sync Upstream Maakrop Release → กดปุ่ม Run workflow เว็บจะอัปเดตเองโดยข้อมูลอยู่ครบ 100%

          

          

            
เปลี่ยนชื่อเว็บหรือย้ายโฮสต์

            
ไปที่ maakrop.com/settings/self-hosted กดปุ่ม ย้ายโดเมน / ยกเลิกการผูก แล้วนำรหัสเดิมไปวางบนเว็บใหม่ได้ทันที (ได้ 3 ครั้งต่อ 30 วัน)

          

        


        

          เปิดหน้าเว็บแล้วขึ้น Error เชื่อมต่อฐานข้อมูลไม่ได้ แก้อย่างไร?
          
เช็ก 2 จุดง่ายๆ: (1) ลองกลับไปกดปุ่ม Run โค้ด SQL ในเมนู SQL Editor ของ Neon อีกครั้ง (2) ตรวจสอบว่าวางค่าทั้ง 5 ช่องใน Vercel ครบและไม่มีช่องว่างเกินด้านหน้าหรือท้ายข้อความ

        

        

          ยังไม่ใส่คีย์ Cloudflare R2 หรือ Gemini AI จะใช้งานอะไรได้บ้าง?
          
ใช้งานฟีเจอร์หลักได้ครบเกือบ 100%! เช็กชื่อ กรอกคะแนน ตัดเกรด ออกข้อสอบ ทำ ปพ.5 และเปิดให้นักเรียนดูคะแนนใช้งานได้ทันที ส่วนรูปภาพ/ไฟล์แนบ (R2 ฟรี 10 GB) หรือผู้ช่วย AI (Gemini) ค่อยกลับมาเพิ่มทีหลังได้ที่เมนูตั้งค่าระบบ

        

        

          ข้อควรจำเกี่ยวกับ MAAKROP_MASTER_KEY
          
แนะนำบันทึกค่า MAAKROP_MASTER_KEY เก็บไว้ในโน้ตส่วนตัว เพราะใช้เข้ารหัสคีย์บริการเสริม (เช่น R2 / Gemini) ที่คุณบันทึกไว้ในฐานข้อมูล หากเปลี่ยนค่านี้ในภายหลังจะต้องกรอกคีย์บริการเสริมใหม่อีกครั้ง
