ภาพรวม & เตรียม 3 บัญชีฟรี

ระบบ Maakrop Self-Hosted สำหรับครูออกแบบมาให้ครูทั่วไปติดตั้งใช้งานเองได้ใน 10 นาที โดยไม่ต้องเขียนโค้ด ไม่ต้องใส่บัตรเครดิต และใช้แผนฟรีตลอดชีพของ 3 บริการมาตรฐานโลก:

1. Neon (ฟรี)

ฐานข้อมูล PostgreSQL ส่วนตัว เก็บรายชื่อนักเรียน เช็กชื่อ คะแนน และไฟล์ตั้งค่าอยู่กับคุณ 100%

เปิด console.neon.tech →

2. Vercel (ฟรี Hobby)

โฮสต์เว็บไซต์ออนไลน์ 24 ชม. เปิดใช้งานได้จากทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

เปิด vercel.com →

3. GitHub (ฟรี)

เก็บสำเนาโปรเจกต์ของคุณและใช้กดปุ่มอัปเดตเวอร์ชันใหม่จาก Maakrop ใน 1 คลิก

เปิด github.com →
สิ่งที่ต้องเตรียมเพิ่ม: รหัสไลเซนส์ MKTH1... จากหน้า maakrop.com/settings/self-hosted (หากได้รับเป็นรหัสสิทธิ์ MKS-... ให้ไปเปิดใช้งานก่อนที่ maakrop.com/shop/redeem)
บทที่ 2 / 9จำเป็น

สร้างฐานข้อมูล Neon + รัน SQL & สร้าง 5 ค่าอัตโนมัติ

  1. เข้า console.neon.tech ล็อกอินด้วย Google/GitHub → กด New Project → ตั้งชื่อโปรเจกต์แล้วเลือก Region เป็น AWS Asia Pacific (Singapore / ap-southeast-1) เพื่อให้ฐานข้อมูลอยู่ใกล้ไทยและตรงโซนกับเซิร์ฟเวอร์ Vercel
  2. กดปุ่ม Connect แล้วคัดลอกลิงก์ของ neondb_owner (ขึ้นต้นด้วย postgresql://neondb_owner...) มาวางในเครื่องมือด้านล่าง
  3. กดปุ่มสร้างค่า — ระบบจะสุ่มรหัสผ่านและคีย์ 64 ตัวอักษรให้ในเบราว์เซอร์ 100% โดยคงบัญชี neondb_owner ไว้ใน DATABASE_URL_UNPOOLED เพื่อสร้างตารางอัตโนมัติตอน Deploy
  4. คัดลอกโค้ด SQL ไปวางในเมนู SQL Editor ของ Neon แล้วกดปุ่ม Run สีเขียวครั้งเดียว (ขึ้น Success ถือว่าเสร็จขั้นตอน Neon)
สุ่มรหัสผ่านและคีย์ความปลอดภัย 64 ตัวอักษรให้อัตโนมัติแล้ว! แนะนำกดปุ่ม ดาวน์โหลดไฟล์สำรอง (.txt) เก็บไว้ 1 ชุด โดยเฉพาะค่า MAAKROP_MASTER_KEY (เปลี่ยนสลับบทไปมาได้โดยค่าที่สร้างไว้ไม่หาย)

บทที่ 3 / 9จำเป็น

              
Deploy บน Vercel (วาง 5 ค่าทีเดียว)

            

            
    
              
  1. กดปุ่ม ติดตั้งบน Vercel (1 คลิก) ด้านบนสุด แล้วล็อกอินด้วยบัญชี GitHub
    2. 
              
  2. ตั้งชื่อโปรเจกต์ของคุณ (เช่น kru-somchai) → กด Create
    3. 
              
  3. ในส่วน Configure Project → Environment Variables: คลิกช่องซ้ายสุดของบรรทัดแรก (DATABASE_URL) แล้วกด Ctrl+V (Mac: Cmd+V) เพื่อวางชุด 5 ค่าที่คัดลอกจากบทที่ 2 (Vercel จะแตกออกเป็น 5 ช่องให้ทันที หรือคัดลอกทีละช่องก็ได้)
    4. 
              
  4. กดปุ่ม Deploy รอประมาณ 1–2 นาที ระบบจะดึงรันไทม์ที่ยืนยันลายเซ็น Ed25519 และรัน migration สร้างตารางให้อัตโนมัติ
    5. 
            

            
โซนสิงคโปร์ (sin1) อัตโนมัติเพื่อให้เว็บเร็ว: แพ็กเกจนี้ตั้งค่าเริ่มต้น Function Region = Singapore (sin1) ให้ใน vercel.json แล้ว เพื่อให้ตรงโซนกับฐานข้อมูล Neon สิงคโปร์ (ap-southeast-1) · หากคุณเคย Deploy เวอร์ชันเก่าไปก่อนหน้านี้ แนะนำเข้าไปตรวจที่ Vercel Project → Settings → Functions → Function Region เลือกเป็น Singapore, Singapore (sin1) → กด Save แล้วกด Redeploy 1 ครั้งครับ

            
แนะนำเก็บรักษาไฟล์สำรอง maakrop-teacher-keys.txt ที่มีค่า MAAKROP_MASTER_KEY ไว้ในที่ปลอดภัย เพราะใช้เข้ารหัสคีย์บริการเสริมทั้งหมดในฐานข้อมูลของคุณ

ตั้งค่าหน้า /setup ครบ 3 ขั้นตอน

    2. 
              
  2. ขั้นที่ 1 (ไลเซนส์): ติ๊กยอมรับเงื่อนไขแล้ววางรหัส MKTH1... — ไม่ต้องตั้ง Setup Key!
    3. 
              
  3. ขั้นที่ 2 (บัญชีครู): ตั้งชื่อห้องเรียน ปีการศึกษา และสร้างอีเมล + รหัสผ่านของครู
    4. 
              
  4. ขั้นที่ 3 (บริการเสริม): สามารถกด "ข้ามขั้นตอนนี้และเปิดใช้งานเลย" เพื่อเริ่มสอนได้ทันที หรือกลับมาตั้งค่าภายหลังในเมนู ตั้งค่าระบบ (/admin/system) ได้ตลอดเวลา
    5. 
            

            
เสร็จเรียบร้อย! เข้าสู่ระบบด้วยบัญชีครูของคุณ แล้วใช้งานเช็กชื่อ คะแนน ตัดเกรด ส่งงาน ปพ.5 และพอร์ทัลนักเรียนได้ทันทีโดยไม่มีลายน้ำ

          


          
          

            

              
บทที่ 5 / 9เสริม · ข้ามได้

              
เก็บรูปภาพและไฟล์ด้วย Cloudflare R2 (ฟรี 10 GB)

            

            
สำหรับอัปโหลดรูปโปรไฟล์นักเรียน ใบลา แนบไฟล์งาน และพอร์ตโฟลิโอ สามารถใช้ Cloudflare R2 แผนฟรี 10 GB/เดือน:

            
    
              
  1. สมัคร/ล็อกอิน Cloudflare Dashboard → ไปที่เมนู R2 Object Storage → กด Create bucket (เลือก Location: APAC เช่น maakrop-files)
    2. 
              
  2. ไปที่ R2 → Manage R2 API Tokens → Create API token เลือกสิทธิ์ Object Read & Write เฉพาะ bucket ของคุณ แล้วจด Access Key ID, Secret Access Key, และ S3 Endpoint URL
    3. 
              
  3. เปิดแท็บ Settings → CORS Policy ของ bucket แล้ววาง JSON ด้านล่าง (เปลี่ยน YOUR-SITE.vercel.app เป็นโดเมนจริงของคุณ):
    4. 
            

            
[
  {
    "AllowedOrigins": ["https://YOUR-SITE.vercel.app"],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]

            

              
            

            
จากนั้นนำค่า Endpoint, Bucket Name, Region ใส่ auto, Access Key ID และ Secret Access Key ไปกรอกที่หน้า /admin/system → แท็บ คีย์และการเชื่อมต่อ (หรือหน้า /setup) แล้วกดทดสอบการเชื่อมต่อ

  • OpenAI / Anthropic / Vercel AI Gateway: นำ API Key ไปใส่ที่หน้า /admin/system → แท็บ คีย์และการเชื่อมต่อ
    • 
            

            
คีย์ทั้งหมดจะถูกเข้ารหัสด้วย MAAKROP_MASTER_KEY ก่อนเก็บลงฐานข้อมูลของคุณ

          


          
          

            

              
บทที่ 7 / 9เสริม · ข้ามได้

              
ส่งอีเมล Resend & ล็อกอินด้วย Google OAuth

            

            

              

                
อีเมลแจ้งเตือน (Resend)

                
แผนฟรีส่งได้ 3,000 ฉบับ/เดือน สมัครที่ resend.com → สร้าง API Key แล้วนำมาใส่ที่ /admin/system → คีย์และการเชื่อมต่อ (สำหรับลืมรหัสผ่านและแจ้งเตือน)

              

              

                
เข้าสู่ระบบด้วย Google

                
สร้าง OAuth Client ที่ Google Cloud Console โดยตั้ง Authorized Redirect URI เป็น:

                https://YOUR-SITE.vercel.app/api/auth/callback/google
              

            

          


          
          

            

              
บทที่ 8 / 9เสริม · ข้ามได้

              
เกมตอบคำถามสด (Ably) & แผนที่เยี่ยมบ้าน (Mapbox)

            

            

              

                
Ably Realtime (เกมสดในห้องเรียน)

                
สมัครฟรีที่ ably.com → คัดลอก Root API Key ไปวางที่ /admin/system → คีย์และการเชื่อมต่อ (หากไม่ใส่ ระบบใช้ Polling อัตโนมัติ)

              

              

                
Mapbox (ปักหมุดแผนที่เยี่ยมบ้าน)

                
สมัครฟรีที่ mapbox.com → คัดลอก Public Access Token (pk....) ไปวางที่ /admin/system (หากไม่ใส่ ระบบใช้ OpenStreetMap ฟรีอัตโนมัติ)

              

            

          


          
          

            

              
บทที่ 9 / 9ดูแลระยะยาว

              
โดเมนส่วนตัว, อัปเดต 1 คลิก & คำถามที่พบบ่อย (FAQ)

            

            

              

                
อัปเดตเวอร์ชันใหม่ใน 1 คลิก

                
เปิด GitHub Repository ของคุณ → แท็บ Actions → เลือก Sync Upstream Maakrop Release → กด Run workflow (Vercel จะอัปเดตเวอร์ชันและ migration ให้อัตโนมัติ ข้อมูลอยู่ครบ 100%)

              

              

                
เปลี่ยนโดเมน / ย้ายเครื่องโฮสต์

                
เข้า maakrop.com/settings/self-hosted กด ยกเลิกการผูกโดเมนเดิม แล้วนำไลเซนส์เดิมไปใช้งานบนโดเมนใหม่ได้ทันที (ย้ายได้ 3 ครั้งต่อ 30 วัน)

              

            

            
วาง 5 ค่าบน Vercel แล้วไม่แตกช่อง ทำอย่างไร?
ให้คลิกที่ช่อง Key ซ้ายสุดของแถวแรกแล้วกด Ctrl+V หรือเลือกคัดลอกทีละช่องจากบทที่ 2 มาวางทีละแถวได้เหมือนกัน

            
เปิดเว็บแล้วช้า หรือขึ้น Error ฐานข้อมูล แก้อย่างไร?
ตรวจสอบ 3 จุด: 1) กด Run โค้ด SQL ในบทที่ 2 ใน Neon SQL Editor จนขึ้น Success แล้ว 2) ค่า DATABASE_URL_UNPOOLED ใช้บัญชี neondb_owner ที่สร้างจากเครื่องมือในบทที่ 2 และไม่มีช่องว่างเกิน 3) ทั้ง Neon และ Vercel Function Region ตั้งอยู่ที่ Singapore (sin1 / ap-southeast-1) เหมือนกัน

            
อัปโหลดรูปนักเรียนไม่ผ่าน ต้องเช็กอะไร?
ตรวจสอบ CORS JSON ในบทที่ 5 ว่าใส่ https:// และโดเมนตรงกับเว็บของคุณทุกตัวอักษรโดยไม่มีเครื่องหมาย / ต่อท้าย

            
ผู้พัฒนาเข้าถึงข้อมูลนักเรียนในฐานข้อมูลเราได้ไหม?
ไม่ได้ 100% — ฐานข้อมูลอยู่บนบัญชี Neon ส่วนตัวของคุณ ตัวแอปตรวจลายเซ็นคีย์ Ed25519 ในเครื่องและซิงก์ต่ออายุใบรับรอง 30 วันในพื้นหลังเป็นระยะเท่านั้น (ดูประวัติการส่งออกทุกครั้งได้ที่ /admin/system)
